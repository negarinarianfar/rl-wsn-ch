# RL-WSN-CH

Reinforcement Learning-based Cluster Head Optimization for Wireless Sensor Networks.

## Overview
This project explores reinforcement learning approaches for energy-efficient cluster head selection in Wireless Sensor Networks (WSNs).

The work extends classical clustering protocols such as SEECP by introducing RL-based multi-role decision policies.

## Features
- Custom WSN simulation environment
- RL-based cluster head selection
- Multi-role agent policies
- Energy-aware optimization
- Comparative evaluation against baseline methods

## Tech Stack
- Python
- NumPy
- Matplotlib
- Reinforcement Learning

## Results
- Improved network lifetime
- Reduced energy imbalance
- Better FND/HND/LND metrics
